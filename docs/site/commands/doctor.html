Command reference

refilm doctor

Check that this machine can record and compare.

Writes files on disk JSON --json Exit 0 · 3 · 1 · 2

Synopsis

refilm doctor [--json] [--dir <project>]

Flags

From refilm doctor --help.
FlagTypeDefaultWhat it does
--dir DIR dir cwd Check that this project directory is writable, and whether it has a run directory yet.
--json flag off Machine-readable result.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
nothingit only reads. Nothing is installed, downloaded or created.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0every required check passed (warnings do not block)
3something required is missing — node, ffmpeg, Chromium or a writable directory
1only optional checks warn
2usage error

Example

refilm doctor
refilm doctor — ready (4 ok, 1 warn, 0 fail)

  ok    node      v26.7.0
  ok    ffmpeg    6.1.1-3ubuntu5 (on PATH)
  ok    chromium  Playwright Chromium 156.0.8078.4 launches and closes
  ok    writable  /home/you/project is writable
  warn  runDir    no .refilm/ in /home/you/project yet
        fix: refilm init            # scaffolds .refilm/ with runs/ and config.json

ready to film (warnings do not block)

Notes

Checks, in order

node ≥ 20 · ffmpeg resolvable through REFILM_FFMPEG, a bundled binary, or PATH · chromium actually launches and closes (30 s timeout) · writable the target directory · run dir whether .refilm/ exists yet.

Every failure carries its fix

The exact command that repairs it, printed under the check. If doctor exits 3, stop and report the missing piece — do not silently install browsers or binaries.

Run it first, every time

It is the cheapest way to avoid discovering a missing library three steps into a capture.
