Command reference

Commands

Twelve commands. Each one has a single job, prints its own --help, and returns one of five documented exit codes. The three that gate — compare, gl compare and verify — exit 1 when the numbers do not match.

The authoritative flag list

Every flag table on these pages is transcribed from refilm <command> --help in version 0.1.2. If a flag is not in the table, it does not exist — run --help on your installed version and compare.

All commands

  • record Film a page and dump everything needed to rebuild its motion. --url --out [options]
  • frames Cut a video or gif into numbered PNG frames with a known time base. --in --out [options]
  • spec Derive the motion spec from a capture, a frame set, a Lottie file or a track. --capture
  • compare Diff a clone's frames against the reference's, frame by frame. --ref --clone --out [options]
  • sheet Labelled contact sheets you can actually look at. filmstrip --frames --out [options]
  • fit Which easing is this curve, and how long does it actually run? --track --selector --prop
  • gl Read or diff a GPU trace written by refilm record --gl. summary
  • verify The gate: evaluate every row of a spec against a clone. --spec --ref --clone [--out ] [--fidelity motion|pixel|mixed] [--region x,y,w,h] [--json]
  • report One self-contained HTML report for a clone run. --dir [--out ] [--title ] [--max-images N] [--check] [--json]
  • install Install the bundled agent skill into an agent's skill directory. --agent claude|codex|dsh|all [--dry-run] [--force]
  • init Scaffold .refilm/ in a project, idempotently. [--dir ] [--force] [--json]
  • doctor Check that this machine can record and compare. [--json] [--dir ]

Exit codes, once

Shared by every command. cli.ts turns a thrown error into the envelope and the code.
CodeNameMeansWhat to do
0successthe command did its jobnothing
1verification failedcompare, gl compare or verify found a mismatch — or report --check found an external referenceread the failing checks, fix one cause, re-record
2usage errora flag is missing or wrong, or a path does not existread the hint: line; fix the command
3environment problemnode, ffmpeg or Chromium is missing or unusablerun refilm doctor and follow its fix lines
4internal errora bug, or the browser died mid-capturere-run with --json and file the error envelope
