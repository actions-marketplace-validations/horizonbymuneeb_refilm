Command reference

refilm install

Install the bundled agent skill into an agent's skill directory.

Writes files on disk JSON --json Exit 0 · 2

Synopsis

refilm install --agent claude|codex|dsh|all [--dry-run] [--force]

Flags

From refilm install --help.
FlagTypeDefaultWhat it does
--agent <t> claude|codex|dsh|all required Target agent. claude → ~/.claude/skills/refilm/; codex → ~/.codex/skills/refilm/; dsh → $DSH_HOME/skills/refilm/ (falling back to ~/.dsh-home/skills/refilm/); all → every target whose parent directory exists.
--dry-run flag off Print what would be copied and where. Change nothing.
--force flag off Overwrite an existing install. Default is never to overwrite.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
<skill dir>/refilm/SKILL.md and references/, copied from the package's own skill/. Nothing is downloaded and nothing outside the three skill directories is touched.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0always — install reports, it does not gate. A skipped target still exits 0.
2usage error — unknown agent name

Example

refilm install --agent all --dry-run
install (dry run) — source /usr/lib/node_modules/refilm/skill

  skip  claude /home/you/.claude/skills/refilm
        /home/you/.claude/skills does not exist, so claude is not installed on this machine
  skip  codex  /home/you/.codex/skills/refilm
        /home/you/.codex/skills does not exist, so codex is not installed on this machine
  keep  dsh    /home/you/.dsh-home/skills/refilm
        already installed — pass --force to overwrite

would install into 0 target(s); 1 already installed, 2 skipped. Nothing was changed.

Notes

The skill is a thin wrapper

It tells the agent when to reach for refilm and how to read the numbers; all the measurement lives in the CLI. Any agent that can run a shell command can use refilm without the skill.

Use --dry-run first

It prints the resolved target paths, which is the fastest way to find out which agents exist on the machine.
