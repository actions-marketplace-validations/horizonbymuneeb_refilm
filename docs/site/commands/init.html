Command reference

refilm init

Scaffold .refilm/ in a project, idempotently.

Writes files on disk JSON --json Exit 0 · 2

Synopsis

refilm init [--dir <project>] [--force] [--json]

Flags

From refilm init --help.
FlagTypeDefaultWhat it does
--dir DIR dir cwd Project directory to scaffold.
--force flag off Rewrite config.json even if it already exists.
--json flag off Machine-readable result.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
.refilm/config.jsondefault viewport, fps, fidelity and run directory.
.refilm/runs/one directory per clone attempt.
.gitignoreadds .refilm/ when a .gitignore exists and does not list it yet.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0the scaffold exists — created or already correct
2usage error — --dir is not a directory

Example

refilm init
  created  .refilm/
  created  .refilm/runs/
  created  .refilm/config.json
  created  .gitignore (+.refilm/)

next:
  refilm record --url <url> --out .refilm/runs/<name>/ref --selector "<section>" --trigger load
  refilm spec   --capture .refilm/runs/<name>/ref --out .refilm/runs/<name>

Notes

Safe to run more than once

Existing files are left alone unless --force is given; the second run prints kept instead of created.

.refilm/ is gitignored

The captures are large and machine-specific. The spec and the scope file are the parts worth committing, if you want to.
