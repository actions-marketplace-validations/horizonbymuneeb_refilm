Command reference

refilm report

One self-contained HTML report for a clone run.

Writes files on disk JSON --json Exit 0 · 1 · 2

Synopsis

refilm report --dir <runDir> [--out <file.html>] [--title <text>] [--max-images N] [--check] [--json]

Flags

From refilm report --help.
FlagTypeDefaultWhat it does
--dir DIR dir required The run directory holding spec.json, clone-*/ and compare-*/.
--out FILE path <runDir>/report.html Output path.
--title TEXT string run dir name Report heading.
--max-images N number 12 Cap on embedded sheet images, to keep the file openable.
--check flag off Verify the written file makes no external requests; exit 1 if it does.
--json flag off Machine-readable result.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
report.htmlone file, images inlined as data: URIs. Zero external references.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0the report was written (and passed --check if given)
1--check found a non-data: src/href in the file on disk
2usage error — --dir is not a directory

Example

refilm report --dir .refilm/runs/hero --out .refilm/runs/hero/report.html
wrote .refilm/runs/hero/report.html (61.8 KB, 2 round(s), 18 spec row(s))
external references: 0 — opens offline

Notes

Every round, not just the winner

A report that quietly omits a failed round is worse than no report. Every round found in the directory is listed, newest last.

--check re-reads from disk

It leaves the file alone, re-reads it and exits 1 when any non-data: src/href is present — so it can gate a report that already exists.

Offline by design

It opens on a plane, in a sandbox, and inside a CI artifact viewer with no network.
