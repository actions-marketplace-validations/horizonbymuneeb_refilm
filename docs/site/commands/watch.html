Command reference

refilm watch

Close the loop: re-record the clone, re-measure it, print one line.

Writes clone frames, compare report JSON --json (one line per run) Exit 0 · 1 · 2

Synopsis

refilm watch --url <url|file.html> --ref <framesDir> [options] [-- record flags...]

Flags

FlagMeaning
--urlPage to record. http(s) is polled by ETag/Last-Modified; a local file by mtime.
--refReference frames directory the clone is measured against.
--outRun directory for the clone and the compare output (default .refilm/watch).
--specGate with refilm verify instead of refilm compare.
--intervalMinimum seconds between runs (default 3).
--onceOne iteration then exit — useful in CI.
--threshold, --motion-threshold, --pixel-thresholdCompare budgets, forwarded verbatim.
--jsonOne JSON line per iteration on stdout.

Change detection

For a local file the watcher compares size and mtime; for an HTTP URL it sends a HEAD request and watches ETag, Last-Modified and Content-Length. One rebuild produces exactly one new measurement.

What it prints

[12:03:04] 80 frames · 7.74% mismatch (budget 5.00%) · start +0.032s · FAIL · 4.4s
[12:03:19] 80 frames · 2.10% mismatch (budget 5.00%) · start +0.004s · PASS · 4.5s

What it writes

  • <out>/clone/ — the latest recording (frames, capture.json, video)
  • <out>/compare/report.json, report.md, diff/NNNN.png

Forwarding record flags

refilm watch --url http://localhost:3000 --ref .refilm/hero/ref -- --selector ".hero" --duration 1800

Exit codes

CodeMeaning
0Interrupted, or --once and the comparison passed
1--once and the comparison failed
2Usage error
