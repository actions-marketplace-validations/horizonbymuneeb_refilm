Command reference

refilm gl

Read or diff a GPU trace written by refilm record --gl.

Writes files on disk JSON --json Exit 0 · 1 · 2

Synopsis

refilm gl summary  <captureDir>
refilm gl channels <captureDir> [--grep RE] [--series KEY]
refilm gl compare  --ref <dir> --clone <dir> [--grep RE] [--map "a=b,c=d"] [--timing 80] [--out report.md]

Flags

From refilm gl --help.
FlagTypeDefaultWhat it does
summary <dir> subcommand — Canvases and renderer settings, three.js scene graph and mixers, shader programs with attribute layouts, draw order per frame, textures, and every animated channel.
channels <dir> subcommand — List channels (kind, range, when they change), or print one channel as [[t, value], …] for fitting.
compare --ref --clone subcommand — Canvas attributes, renderer settings and draw structure side by side, then every animated channel.
--grep RE regex — Filter channels by name.
--series KEY string — Print one channel as a series.
--map "a=b,c=d" map — Map reference channel names to the clone's when they differ.
--timing MS ms 80 Allowed start/end difference per channel.
--out FILE path — Write the comparison as markdown.
--json flag off Machine-readable result on stdout.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
stdout / --outnothing is written into the capture; --out writes the compare markdown.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0read successfully, or every channel passed
1gl compare: at least one channel failed
2usage error — no GPU trace in that directory, or a bad subcommand

Example

refilm gl summary .refilm/runs/hero/ref
refilm gl channels .refilm/runs/hero/ref --grep emissive
# GPU trace: .refilm/runs/hero/ref

renderer: ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device), SwiftShader driver) · 112 frames traced · 1 draw calls per frame

## Canvases
- c1 webgl on canvas#c: 480×360 px, css 480×360 at 0,0 (pixel ratio 1), antialias true, alpha true

## Programs (shaders in gl/shaders/)
- **p1**: 1/frame, TRIANGLE_STRIP up to 4 verts, no-blend (gl/shaders/p1.vert, gl/shaders/p1.frag)
  - animated: uHover
  - fixed: uTint=[0.35,0.55,1]

## Animated channels (1)
- p1.uHover: there-and-back, 0.000037791 → 0.99989, changes -650–1183 ms

Notes

Channel kinds are the useful part

clock, transition, there-and-back, oscillation, steps. Each tells you how to implement it, not just that it moves. The full table.

Fixed uniforms are art direction

gl summary separates constant uniforms from animated channels. Copy the constants exactly — one wrong constant changes the whole look.

gl compare exits 1

Same gate contract as verify: same kind, start and end within --timing ms, mean value error ≤ 5% of the reference's range.
