Command reference

refilm sheet

Labelled contact sheets you can actually look at.

Writes files on disk JSON --json Exit 0 · 2

Synopsis

refilm sheet filmstrip --frames <dir> --out <dir> [options]
refilm sheet compare   --ref <dir> --clone <dir> --out <dir> [options]

Flags

From refilm sheet --help.
FlagTypeDefaultWhat it does
--fps N number 25 Used for the time labels. Default from frames.json / capture.json beside the frames.
--cols N number 6 Filmstrip: columns per sheet.
--per-sheet N number 24 / 8 Frames per sheet: 24 for filmstrip, 8 for compare.
--width N px 240 / 420 Rendered width of each frame: 240 filmstrip, 420 compare.
--every K number 1 Show every K-th frame.
--from I --to J index all Frame index range, inclusive, 0-based.
--diff <dir> dir — Compare: diff images from refilm compare, drawn as a third column.
--offset K number 0 Compare: clone frame = reference frame + K. Take it from report.json.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
sheet-01.png, sheet-02.png …and prints their paths. With --json the payload is { files: [...] }.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0sheets were written
2usage error — no PNG frames in the given directory

Example

refilm sheet filmstrip --frames .refilm/runs/hero/ref/frames --out ref/sheets --cols 6
refilm sheet compare --ref ref/frames --clone clone-1/frames \
  --diff compare-1/diff --out compare-1/sheets --every 2
rendered ref/sheets/sheet-01.png
ref/sheets/sheet-01.png

rendered compare-1/sheets/sheet-01.png
rendered compare-1/sheets/sheet-02.png
compare-1/sheets/sheet-01.png
compare-1/sheets/sheet-02.png

Notes

This is not optional

The numbers say something is off; the sheets say what. Read every sheet, not just the first — the interesting part of a motion is usually the middle, and the last frames tell you whether the end state holds.

Filmstrip before you build

Look at the reference's own frames before writing any code. It costs one command and saves a round.
