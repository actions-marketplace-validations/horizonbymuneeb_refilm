Command reference

refilm record

Film a page and dump everything needed to rebuild its motion.

Writes files on disk JSON --json Exit 0 · 2 · 3 · 4

Synopsis

refilm record --url <url|file.html> --out <dir> [options]

Flags

Window

From refilm record --help.
FlagTypeDefaultWhat it does
--viewport WxH WxH 1440x900 Viewport to film at. Use the same value for the reference and the clone.
--scale N number 1 Device scale factor (deviceScaleFactor).
--color-scheme S light|dark — Force the page's colour scheme.
--reduced-motion S no-preference|reduce no-preference Emulate prefers-reduced-motion.

What to look at

From refilm record --help.
FlagTypeDefaultWhat it does
--selector CSS css whole viewport Element to scroll into view and crop frames to.
--pad PX number 0 Extra margin around the selector crop.
--clip x,y,w,h numbers — Explicit crop in CSS px. Overrides the --selector crop.

How to start the motion

From refilm record --help.
FlagTypeDefaultWhat it does
--trigger T load|scroll|hover|leave|move|drag|click|none load What starts the motion. load films from navigation; scroll wheels the page in steps; hover, click and move act on --target; leave is hover-out; drag is move with the button held; none just records loops.
--target CSS css — Element to hover, click or move over.
--hover-at FX,FY fractions 0.5,0.5 Where to put the pointer on --target, as fractions of its box.
--pre-hover CSS css — Hover this element before the trigger, and wait --pre-hover-ms.
--pre-hover-ms MS ms 1500 Wait after --pre-hover before triggering.
--leave-to X,Y px <width/2>,8 Viewport point the pointer moves to for --trigger leave.
--path "FX,FY;…" fractions — For move/drag: fractional points inside --target, visited in order.
--path-ms MS ms 400 Time spent between two points on the path.
--scroll-to PX|CSS px|css — Scroll position (or element) to reach during a scroll trigger.
--scroll-ms MS ms 600 How long the stepped scroll takes.
--scroll-steps N number 12 Number of wheel steps.
--wait-before MS ms 800 Settle time after load before the trigger fires.
--pre-js FILE|CODE path|js — JS to run after load and before the trigger — dismiss a banner, open a menu, set a scroll position.
--duration MS ms 3000 How long to record after the trigger.
--pre-roll MS ms 200 Frames to keep before the trigger.

Output

From refilm record --help.
FlagTypeDefaultWhat it does
--fps N number 25 Extracted frame rate.
--playback-rate R number 1 Slow CSS/WAAPI animations with CDP (0.25 = 4× slower). JS-driven motion is unaffected.
--track "CSS, CSS" css list --selector, if any Elements sampled every animation frame into track.json.
--no-video flag off Skip the video and frames; keep inspection and track only.
--headed flag off Show the browser. Needs a display.
--json flag off Machine-readable summary on stdout.

Canvas, WebGL and 3D

From refilm record --help.
FlagTypeDefaultWhat it does
--clock real|virtual enum real real records the page and cuts frames out of the video. virtual runs the page on a clock the capturer advances by hand, so frame k is exactly t = k/fps and two captures are identical.
--seed N number 1 (virtual) Seed Math.random. Same seed, same particles.
--raf-hz N number 60 Virtual-clock frame rate seen by the page.
--network-wait MS ms 3000 Virtual clock: wait up to MS for in-flight work before each frame.
--gl flag off Trace WebGL/WebGL2/WebGPU/canvas 2D and three.js, Pixi, PlayCanvas, Babylon, OGL: shaders, programs, draw calls, textures, buffers, uniforms and the scene graph, per frame.
--gl-buffers MB MB off With --gl, also dump vertex/index buffer contents (first upload) up to MB.
--gpu software|hardware enum software software is SwiftShader — slower, identical pixels everywhere. hardware uses the real GPU and enables WebGPU. Film both sides with the same mode.
--assets flag off Save the page's 3D models, textures, shader files, Lottie/Rive files and scripts into assets/ + assets.json.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
video.webm / video.mp4video.mp4 under --clock virtual.
frames/NNNN.png, frames.jsonnumbered frames and their time base.
inspect.jsondeclared CSS/WAAPI animations with exact timing, computed styles, fonts, detected libraries.
track.jsonper-frame position, size, opacity and transform of every --track selector.
capture.jsonthe settings that produced the run. compare reads both sides and warns when they disagree.
gl/gl.json, gl/draws.json, gl/shaders/, gl/summary.md, gl-track.json, three/only with --gl.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0the capture was written
2usage error — missing --url or --out, bad flag value
3environment problem — ffmpeg or Chromium unavailable
4internal error — the browser died or a write failed

Example

refilm record --url https://example.com --out .refilm/runs/hero/ref \
  --selector ".hero" --trigger load --duration 1800 \
  --track ".eyebrow, h1, .sub, .card"
[launch] chromium (software gl, 1440x900 @1x)
[load] https://example.com
[inspect] animations, keyframes, styles, fonts, libraries
[frames] cutting frames out of video.webm
[write] capture.json
capture     .refilm/runs/hero/ref
viewport    1440x900 @1x · 25 fps · real clock
frames      50 · cropped 1080x409 at 180,245
trigger     load · trigger frame 5 · 1800 ms
motion      9 animations · 3 keyframes · 0 canvases · 33 nodes
track       62 samples of .eyebrow, h1, .sub, .card

Notes

--track is the highest-value flag

It is the only thing that produces a numeric curve per element, which is what fit and verify need. Track the elements you will animate, plus any parent that moves.

Same settings on both sides

A different viewport, crop, fps, trigger or clock means you are measuring your setup, not the clone. Re-run with only --url and --out changed.

Virtual clock for canvas

Software GL drops frames on the real clock, and the drop is machine-dependent. --clock virtual makes frame k exactly t = k/fps. See Determinism.

Long durations drop frames

Keep reference and clone short (≤ 3 s) and identical in length on a software-GL box.
