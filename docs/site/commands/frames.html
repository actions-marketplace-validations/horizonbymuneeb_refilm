Command reference

refilm frames

Cut a video or gif into numbered PNG frames with a known time base.

Writes files on disk JSON --json Exit 0 · 2 · 3

Synopsis

refilm frames --in <file.mp4|.webm|.mov|.gif> --out <dir> [options]

Flags

From refilm frames --help.
FlagTypeDefaultWhat it does
--fps N number 10 Frames per second to keep. 25–30 for fast motion, 5 for long sequences.
--start T time 0 First moment to keep: "0:03", "3.5", "1500ms".
--end T time end of file Last moment to keep, same formats.
--crop x,y,w,h numbers — Crop in source pixels.
--width W number source width Downscale the output to this width, aspect preserved.
--probe flag off Print the source's duration, size and frame rate, extract nothing.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
NNNN.png0001.png is the first kept frame.
frames.jsonfps, count, start, sourceWidth, sourceHeight, sourceFps.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0frames were written (or --probe printed the source)
2usage error — no --in, file missing, bad time format
3ffmpeg could not read the file

Example

refilm frames --in clip.mp4 --probe
refilm frames --in clip.mp4 --out ref/frames --fps 10 --start 0:00.4 --end 0:01.2
source: /work/clip.mp4
duration: 2.000s
size: 640x360
frame rate: 25 fps

wrote 8 frames at 10 fps to ref/frames
source 640x360 @ 25 fps, 2.00s
time range 0.400s – 1.200s
files 0001.png … 0008.png

Notes

The time base is the point

Frame i (0-based) sits at t = start + i / fps seconds of the source, so a frame index from compare or sheet maps straight back onto the recording.

Probe first

Run --probe before choosing --crop: you need the source size to work out where the section actually is.

Screen recordings need care

A recording of someone else's screen has a cursor, browser chrome and compression noise. Crop them out and raise compare --pixel-threshold slightly instead of chasing noise.
