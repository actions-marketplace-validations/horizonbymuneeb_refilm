Command reference

refilm verify

The gate: evaluate every row of a spec against a clone.

Writes files on disk JSON --json Exit 0 · 1 · 2 · 3

Synopsis

refilm verify --spec <spec.json> --ref <captureDir|framesDir> --clone <captureDir|framesDir> [--out <dir>] [--fidelity motion|pixel|mixed] [--region x,y,w,h] [--json]

Flags

From refilm verify --help.
FlagTypeDefaultWhat it does
--spec <file> file required The spec to hold the clone to, from refilm spec.
--ref <dir> dir required The reference capture: frames/ plus an optional track.json.
--clone <dir> dir required The clone capture, made the same way.
--out <dir> dir — Write verify.json and verify.md here.
--fidelity <level> motion|pixel|mixed the spec's Which checks run.
--region x,y,w,h numbers whole frame For mixed: the cloned region, in reference pixel coordinates.
--threshold T 0..1 0.02 Mean-mismatch limit for the pixel gate.
--json flag off Machine-readable result.

What it writes

Paths are relative to the directory you pass on the command line.
WritesWhat is in it
verify.jsonper-check status, measured, limit, detail, plus counts and artifacts.
verify.mdthe same, for a human.

Exit codes

Exit codes. The full contract is on Using it from an agent.
CodeMeaning
0every check passed or skipped
1at least one check failed
2usage error — missing flag, no such spec
3environment problem

Example

refilm verify --spec .refilm/runs/hero/spec.json \
  --ref .refilm/runs/hero/ref --clone .refilm/runs/hero/clone-1 \
  --out .refilm/runs/hero/verify-1
verify hero — motion fidelity: 12 pass, 37 fail, 11 skip
  PASS div.eyebrow opacity start — -34 ms (limit ±80 ms)
  FAIL div.eyebrow opacity end — -209 ms (limit ±80 ms)
       reference 635 ms, clone 426 ms
  FAIL div.eyebrow opacity easing — ease-out → linear (limit family ease-out, or ≤5% of travel)
       the clone is linear where the reference is ease-out: that is a different kind of motion, not a near miss (curve distance 4.1%)
  FAIL article.card stagger — -100, -100 ms (limit ±40 ms)
       spec gaps 100, 100 ms; clone gaps 0, 0 ms
  SKIP div.bar[0] scaleX timing
       the reference track has no scaleX series for div.bar[0] (tracked: .eyebrow, h1, .sub, .card)
  PASS nothing extra is moving — 0 (limit 0)

result: FAIL — 37 check(s) failed (exit 1)
note: 11 check(s) skipped; a skip is not a pass — see the reasons above

Notes

The exit code is the product

1 while the clone does not match. It turns "looks about right" into a gate an agent or a CI job can loop on.

Checks per fidelity

motion: start/end/duration ±80 ms, easing family or ≤5% of travel, stagger gaps ±40 ms, travel ≤10%, nothing moving that should be still. pixel: mean mismatch ≤2%, no frame above 5%, rest frames ≤0.5%, fonts identical. mixed: the cloned region passes one of the above; additions are not compared.

A skip is not a pass

An unmeasurable check names what was missing and stays skip. A green run that skipped its checks is worse than a red one.
